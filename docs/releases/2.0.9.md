# KafkaPilot 2.0.9

## 한국어

- 서버 그룹을 만들고 접거나 펼칠 수 있습니다. 드래그 또는 우클릭 메뉴로 서버를 그룹 간 이동하고, 그룹과 서버 순서를 변경할 수 있습니다. 그룹은 설정 Export/Import에 포함되며, 그룹을 삭제해도 서버는 유지됩니다.
- 사이드바를 더 조밀하게 정리하고, 서버 검색에 그룹 이름과 접힌 그룹의 서버를 포함했습니다. 작은 창에서도 메시지 그리드와 Viewer의 구분선과 높이가 안정적으로 유지됩니다.
- 토픽·브로커 설정을 변경할 때 다른 사용자 설정이 초기화되던 문제를 수정했습니다.
- Interval Produce를 빠르게 중지·재시작할 때 이전 전송 루프가 다시 실행되던 문제를 수정했습니다. Live 연결 대기 중 탭 닫기·중지·화면 분할 이동도 세션별로 처리하며, 이전 세션의 늦은 응답과 이벤트를 무시합니다.
- 토픽 상세 정보의 응답 순서가 바뀌어도 현재 선택한 토픽의 정보를 표시합니다.
- Offset/Time 조회별 Consumer Group을 분리했습니다. 느린 시작이나 Avro 디코딩 중 메시지가 누락되던 문제, 연결·구독 실패 후 정리 누락, 역순 전체 Export의 중복 조회를 수정했습니다.
- 검색 정규식의 역슬래시를 보존하고, 상태를 가진 정규식도 메시지마다 일관되게 비교합니다.
- 설정 Import에서 언어와 사이드바 접힘 상태를 복원합니다. Font Reset은 글꼴·크기·굵기만 초기화하고 Export 템플릿을 유지합니다. 백업 폴더 생성, 원본 설정 파일 누락 시 복원, 저장·복원 중 경쟁도 수정했습니다.
- Map Auto Fit이 자동 확대·축소 후 해제되던 문제를 수정했습니다. 지도와 백그라운드 버퍼는 최근 갱신된 ID 5,000개를 유지하고, 오래된 ID의 마커·경로·애니메이션을 정리합니다. Kafka 원본과 녹화 파일에는 영향을 주지 않습니다.

토픽·브로커 설정 변경에는 IncrementalAlterConfigs v0를 지원하는 **Kafka 2.3 이상**이 필요합니다. 미지원 브로커에서는 오류를 표시하며 기존 설정 전체를 대체하지 않습니다.

이번 배포 대상은 Windows x64입니다. 설치 파일은 코드 서명되지 않았으며, macOS 설치 파일은 포함하지 않습니다. 115개 회귀 테스트, 타입 검사·빌드와 독립 코드 리뷰를 통과했습니다. 실제 Kafka 연결·발행·녹화·설정 변경의 통합 테스트와 설치·업그레이드 테스트는 수행하지 않았습니다. 자세한 수정 근거와 검증 범위는 [감사 후속 수정 기록](https://github.com/pjhun0412/KafkaPilot/blob/v2.0.9/docs/incidents/2026-10-08-audit-fixes.md)을 참고하세요.

## English

- Create collapsible server groups, move servers between groups by dragging or using the context menu, and reorder groups and their members. Groups are included in settings export/import; deleting a group keeps its servers.
- Make the sidebar more compact and include group names and collapsed members in server search. Keep the message grid/Viewer divider and pane heights stable in small windows.
- Update topic and broker settings without resetting unrelated overrides.
- Prevent stopped Interval Produce loops from resuming after a quick restart. Track pending Live starts, tab closure, stop actions, and split-pane moves by session, ignoring obsolete responses and events.
- Keep topic details aligned with the selected topic when responses arrive out of order.
- Use a separate Consumer Group for each Offset/Time request. Fix missing messages during slow starts or Avro decoding, cleanup after connection/subscription failures, and duplicate pages in descending full exports.
- Preserve backslashes in search regex literals and make stateful regex comparisons consistent across messages.
- Restore language and collapsed sidebar state during settings import. Font Reset restores only the font family, size, and weight while preserving the Export template. Fix backup directory creation, recovery when the primary settings file is missing, and races between saving and recovery.
- Keep Map Auto Fit enabled during automatic zooming. Retain the 5,000 most recently updated IDs in the viewer and background buffer, removing evicted markers, trails, and animations. Kafka records and recorded files are unaffected.

Topic and broker configuration updates require **Kafka 2.3 or later** with IncrementalAlterConfigs v0 support. Unsupported brokers report an error instead of replacing the complete configuration.

This release targets Windows x64. The installer is not code-signed. No macOS installer is included. All 115 regression tests, type checks, the build, and independent code review passed. Live Kafka connection, produce, recording, and configuration-change integration tests, and installation/upgrade tests were not performed. See the [audit fixes](https://github.com/pjhun0412/KafkaPilot/blob/v2.0.9/docs/incidents/2026-10-08-audit-fixes.md) for evidence and validation limits.
