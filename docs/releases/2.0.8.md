# KafkaPilot 2.0.8

## 한국어

- 큰 숫자와 선행 0을 포함한 메시지 Key를 Kafka에서 받은 원문 문자열 그대로 표시합니다.
- Map 설정에서 WGS84 정수 좌표(E6, ÷1,000,000)를 지원합니다.
- 저장한 좌표 필드 경로를 실시간 수신 메시지에도 적용합니다.
- Map Viewer 차량 마커의 색상, 진행 방향, 선택 표시, 경고와 이름표를 개선했습니다.
- 잘못된 Dynamic Field 토큰의 오류 표시, 분할 화면의 Produce 대상 토픽 전환, Consumer Group 상태 확인 실패 시 Offset Reset 차단을 수정했습니다.

정수 좌표를 사용하려면 Map 설정에서 Y/Lat를 `value.currentLat`, X/Lng를 `value.currentLng`로 지정하고 **WGS84 정수 좌표 (÷1,000,000)**를 선택하세요. 예를 들어 `37757309`, `128905820`은 `37.757309`, `128.905820`으로 표시됩니다. 기존 소수점 좌표와 밀리초·TM·UTM 형식도 계속 사용할 수 있습니다.

이번 배포 대상은 Windows x64입니다. 설치 파일은 코드 서명되지 않았으며, macOS 설치 파일은 포함하지 않습니다.

## English

- Preserve Kafka message keys as their original strings, including large integers and leading zeros.
- Support WGS84 integer coordinates (E6, ÷1,000,000) in Map settings.
- Apply saved coordinate field paths to incoming live messages.
- Improve Map Viewer vehicle colors, heading indicators, selection outlines, alerts, and labels.
- Fix invalid Dynamic Field validation, split-pane Produce topic activation, and Offset Reset protection when the Consumer Group state cannot be verified.

For integer coordinates, set Y/Lat to `value.currentLat`, X/Lng to `value.currentLng`, and select **WGS84 integer coordinates (÷1,000,000)**. For example, `37757309`, `128905820` becomes `37.757309`, `128.905820`. Existing degree, milliarcsecond, TM, and UTM formats remain supported.

This release targets Windows x64. The installer is not code-signed. No macOS installer is included.
